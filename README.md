## Run locally

```bash
npm install
npm start
```

This project uses Create React App. `npm run build` creates a production build.

## Daily blog

Open the **Blog** section and click **+ New post** to publish a daily entry. Pick a category, set the date, and write what you learned in your own words. Posts can be edited or deleted and persist in localStorage.
